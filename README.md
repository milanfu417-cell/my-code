# my-code

## 食物/醬料保存期限提醒

單一 HTML 檔案的網頁 App（`index.html`），使用 React + Tailwind CSS（皆透過 CDN 載入，免安裝、免建置）。

用法：直接用瀏覽器開啟 `index.html`，或用任意靜態伺服器（例如 `npx serve .`）啟動。

功能：
- 手動新增食物（名稱、分類、開封/購買日期、保存期限）
- 保存期限可選日期，也可用「剩餘天數」快速輸入（3/7/14/30/90 天或自訂）
- 分類可自訂，支援依分類篩選、依名稱搜尋
- 首頁清單依剩餘天數由少到多排序，並用顏色標示緊急程度（紅／橘／黃／綠）
- 可編輯、刪除項目
- 資料儲存在瀏覽器 localStorage，重新整理不會消失
- 手機優先的卡片式版面，桌面版同樣可用

拍照辨識功能（呼叫 Claude API 自動辨識食品名稱與保存期限）尚未實作，待後續確認金鑰處理方式後再串接。
